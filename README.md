# Amazon Clone

A responsive Amazon homepage clone built using React and Vite. This project recreates the look and feel of Amazon's landing page while demonstrating modern frontend development practices.

## Website Chosen

- Amazon (https://www.amazon.in)

## Tech Stack Used

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Git & GitHub
- Render (Deployment)

## Features Implemented

- Responsive Amazon-inspired homepage
- Navigation bar with search functionality
- Hero banner section
- Product cards and product grid
- Horizontal product scrolling section
- Footer section
- Component-based architecture using React
- Clean and reusable code structure
- Deployed online using Render

## Known Limitations

- This is a frontend clone only.
- User authentication is not implemented.
- Shopping cart and checkout functionality are not available.
- Backend services and database integration are not included.
- Search redirects to Amazon instead of searching locally.
- Product data is static and used for demonstration purposes.

## Installation

1. Clone the repository

```bash
git clone https://github.com/abhaygupta-craxzy/Amazon-clone.git
```

2. Navigate to the project directory

```bash
cd Amazon-clone
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```
